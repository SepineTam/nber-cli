# NBER-CLI v0.11.2 Release Notes

NBER-CLI v0.11.2 corrects product website links in package metadata, plugins, and documentation.

## Fixed

- Package and Claude/Codex plugin homepage fields now point to https://aidea-labs.com/open/projects/nber-cli.
- English and Chinese README files and documentation include product website and AIdeaLabs links.
- Documentation navigation and footer provide direct links to the product website.

## Installation

```bash
uv tool install --upgrade nber-cli==0.11.2
```

Desktop installers for macOS, Windows, and Linux are attached to this release.
