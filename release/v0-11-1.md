# NBER-CLI v0.11.1 Release Notes

NBER-CLI v0.11.1 is a patch release that makes NBER paper search and metadata lookup more reliable. It has no database migration, configuration change, breaking API change, or security-boundary change.

## Fixed

- Search now retries malformed responses, HTTP 408/429 responses, and transient NBER server failures before returning a clear error.
- Paper detail lookup retries temporarily invalid pages and uses resilient HTML metadata parsing instead of attribute-order-sensitive regular expressions.
- Historical Paper IDs such as `h0065` remain intact in search results and are accepted by the MCP paper-info tool.
- HTML entities such as `&amp;` and `&#039;` are decoded in paper metadata.

## Installation

```bash
uv tool install --upgrade nber-cli==0.11.1
```

Or run the MCP server without a persistent installation:

```bash
uvx --from nber-cli==0.11.1 nber-cli mcp-server
```
